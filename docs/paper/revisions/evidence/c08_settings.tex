\section{Selected operating settings}
\label{app:settings}
The selection uses the same feasible front and role definitions as section~\ref{sec:audit}.
All six parameter vectors are distinct. Phases are absolute ASTRA input phases, not
calibrated off-crest values. The supporting CSV supplies the stable run/evaluation mapping,
all exit diagnostics and signed margins against every production inequality. Complete
trajectory samples and source hashes are retained with the reproducible analysis.
