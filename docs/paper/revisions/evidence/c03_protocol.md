# C03 exploratory front-analysis protocol

Protocol specified before generating the C03 result files. The archived primary profile and original labels are authoritative; no new tracking, relabeling, or campaign selection is performed.

- Analyze all 30 completed stage-04 campaigns, grouped by their ten shared initial designs. Validate evaluation order, uniqueness, budget (160), and equality of the six initial design variables across each matched group (first 16 evaluations).
- Minimize horizontal/vertical normalized emittance and total RMS energy spread. Divide recorded physical values by (1e-6 m rad, 1e-6 m rad, 1e6 eV), producing coordinates in micrometre radian, micrometre radian and MeV. These display-unit scales are conventions, not physical acceptance limits; the resulting indicators depend on the scale choice.
- Use every evaluation in the budget, including invalid and infeasible evaluations. Only finite valid jointly feasible objective vectors enter fronts. Collapse exact objective duplicates for set indicators; preserve all original records.
- Checkpoints are 16,24,...,160 evaluations, with full initial design at 16. No interpolation or per-evaluation treatment of a simultaneously proposed batch is used.
- The empirical reference set R is the exact nondominated set of unique feasible objective vectors pooled across all methods and all terminal runs. It approximates observed coverage, not the true front. Shared construction introduces self-inclusion bias; terminal leave-one-matched-group-out IGD+ is a sensitivity analysis with each held-out group omitted from R.
- Additive epsilon I(A,R) = max_r min_a max_j(a_j-r_j), lower is better. IGD+ = mean_r min_a ||max(a-r,0)||_2, lower is better. Both use normalized minimization coordinates and the same R. Empty A gives positive infinity; no available objective is invented. Empty R is an error.
- Directional coverage C(A,B) is the fraction of unique feasible nondominated vectors in B weakly dominated by A. C(empty,B)=0 for nonempty B; C(A,empty) is undefined (reported missing), not 1. Coverage is reported in both directions within each matched group.
- Exploratory HV uses three fixed post-hoc references: pooled empirical-front coordinate nadir plus 10%, 25%, and 50% of the pooled-front coordinate spans. These data-derived, finite-set references are sensitivity choices, not engineering limits. Retain the original reporting reference unchanged. Points outside a reference contribute no dominated volume; preserve them in all other analyses and record excluded-front counts. HV is dimensionless after display-unit normalization.
- Empirical attainment uses targets R+delta with componentwise deltas of 0.05,0.10,0.25,0.50 normalized units: report the across-run probability of weakly dominating each target, and its mean over targets. This is tolerance-dependent empirical attainment of observed trade-offs; it is not a global Pareto claim.
- Report per-run traces, across-run medians/interquartile ranges and terminal summaries. Trace bands use nearest-rank quartiles to retain infinite empty-front scores; infinite aggregate scores are shown as gaps, without omitting empty runs. Terminal table quartiles use linear interpolation (all terminal fronts are nonempty). Sample-efficiency is shown by batch-checkpoint traces, with equal budgets. No preferred metric/reference will be selected after looking at rankings.
- All analyses are post hoc/exploratory. Primary physical validation, archived feasibility, seeds, precision, and reporting metadata remain immutable. New paired inference is specified separately in C04 before computing it.
