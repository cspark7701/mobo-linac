\section{Chronological predictive validation}
\label{app:predictive}
Every saved model is evaluated only on its subsequent batch, using recorded hyperparameters
and effective fixed noise. The supporting records include per-observation predictions,
interval widths and training identities. Rows are pooled descriptive summaries of adaptive
sampling, not independent calibration trials. Constant transmission is excluded from the
error-discrimination table because no failed-transmission example was observed.
