Multi-Objective Bayesian Optimization for a 200 MeV Electron Injector Linac

A high-performance Machine Learning framework combining BoTorch \(q\text{LogNEHVI}\) acquisition functions with process-safe ASTRA beam dynamics simulations to learn true non-dominated Pareto fronts under physical beam constraints.

1. Framework Overview ¶

This repository implements a multi-objective Bayesian optimization (MOBO) pipeline for an S-band electron injector accelerator. It replaces traditional scalarized weighted objectives with direct Pareto front learning using Gaussian Process (GP) surrogates and hypervolume maximization.

🔬 Accelerator Physics Model

High-fidelity particle tracking with ASTRA (v3.2) using 2D cylindrical space-charge field solvers (\(N=10,000\) macroparticles, \(Q=250\text{ pC}\)) across a 200 MeV linac featuring RF gun, solenoid, 4 ACC cavities, and quad doublets.

🛡️ Process-Safe Isolation

Every parallel simulation worker executes inside a dedicated, isolated evaluation directory (results/<run_id>/work/eval_00000i/), completely eliminating multi-threaded file race conditions.

🎯 Constrained \(q\text{LogNEHVI}\)

Parallel candidate batch proposals (\(q=4\)) driven by Noisy Expected Hypervolume Improvement, weighted by explicit Gaussian Process Probability of Feasibility constraint models.

⚡ Objective Conventions & Constraint Rules

Physical Objectives (Minimize): Horizontal emittance (\(\varepsilon_{n,x}\)), Vertical emittance (\(\varepsilon_{n,y}\)), and RMS energy spread (\(\sigma_E\)). In BoTorch model space, objectives are negated (\(\mathbf{Y}_{\text{model}} = -\mathbf{Y}_{\text{phys}}\)).
Constraints: \(\sigma_x, \sigma_y \le 1.0\text{ mm}\), \(\sigma_{x'}, \sigma_{y'} \le 1.0\text{ mrad}\), \(\sigma_z \le 1.0\text{ mm}\), \(195.0 \le E_{\text{kin}} \le 205.0\text{ MeV}\), and \(\eta_{\text{trans}} \ge 90.0\%\).

3. Software Architecture & Execution Pipeline ¶

Modular execution pipeline decoupling simulation management from Bayesian optimization algorithms. 

Parameter Vector (6D) ➔ Modify astra.in ➔ ProcessPoolExecutor Worker ➔ Run ASTRA Simulation 
    ➔ Parse Statistics ➔ Compute Objectives & Constraints ➔ Update ModelListGP Surrogates 
    ➔ Optimize qLogNEHVI ➔ Propose Next Candidate Batch (q=4)

6. Quick Setup & Execution ¶

Set up environment and verify installation on Linux 64-bit platforms: 

# 1. Clone Repository
git clone https://github.com/cspark7701/mobo_linac.git
cd mobo_linac

# 2. Automated Installer Setup (Creates Conda env & installs dependencies)
./install.sh --create-env

# 3. Load Environment Variables & Activate
conda activate linac-opt
source env_setup.sh

# 4. Run Pytest Suite Verification
pytest -v -m "not integration"
