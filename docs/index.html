Multi-Objective Bayesian Optimization for a 200 MeV Electron Injector Linac

A high-performance Machine Learning framework combining BoTorch $q\text{LogNEHVI}$ acquisition functions with process-safe ASTRA beam dynamics simulations to learn true non-dominated Pareto fronts under strict physical constraints.

Explore Interactive Pareto Results Read Consolidated Technical Report (PDF)

1. Framework Overview

Advanced Bayesian Optimization replacing scalarized weighting with multi-objective hypervolume maximization.

🔬 Accelerator Physics Modeling

Accurate 6D particle tracking using ASTRA (v3.2) with 2D cylindrical space-charge field solvers ($N=10,000$ macroparticles, $Q=250$ pC) across a 200 MeV linac featuring RF gun, solenoid, 4 ACC cavities, and quad doublets.

🛡️ Process-Safe Isolation

Every parallel simulation runs inside a dedicated evaluation directory (results/<run_id>/work/eval_00000i/), eliminating multi-threaded file race conditions and log corruptions.

🎯 Constrained $q\text{LogNEHVI}$

Parallel batch candidate proposals ($q=4$) driven by Noisy Expected Hypervolume Improvement weighted by explicit Gaussian Process probability of feasibility surrogates.

🎯 Physical Objectives (Minimize)
  • Horizontal Emittance ($\varepsilon_{n,x}$): Transverse beam quality
  • Vertical Emittance ($\varepsilon_{n,y}$): Transverse beam quality
  • RMS Energy Spread ($\sigma_E$): Longitudinal energy homogeneity
🛡️ Beam Quality Constraints
  • $\sigma_x, \sigma_y \le 1.0\text{ mm}$ (RMS Transverse Size)
  • $\sigma_{x'}, \sigma_{y'} \le 1.0\text{ mrad}$ (RMS Divergence)
  • $\sigma_z \le 1.0\text{ mm}$ (RMS Bunch Length)
  • $195.0\text{ MeV} \le E_{\text{kin}} \le 205.0\text{ MeV}$ (Beam Energy)
  • $\eta_{\text{trans}} \ge 90.0\%$ (Transmission Efficiency)

6. Quick Setup & Installation

Get up and running in a single command on Linux 64-bit platforms.

# 1. Clone Repository
git clone https://github.com/cspark7701/mobo_linac.git
cd mobo_linac

# 2. Automated Installer Setup
./install.sh --create-env

# 3. Load Environment Variables & Activate
conda activate linac-opt
source env_setup.sh

# 4. Run Pytest Suite Verification
pytest -v -m "not integration"
